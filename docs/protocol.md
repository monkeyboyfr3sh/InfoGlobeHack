# Olympia Infoglobe IR protocol

Findings from testing the globe with the firmware's Protocol Explorer (web UI → Explorer tab).
Raw observations are kept on the globe (`GET /notes`); this page is the cleaned-up summary.

Status: **work in progress** (last updated 2026-11-01).

## Link layer

| Property | Value |
|---|---|
| Carrier | 38.54 kHz, 50 % duty |
| Bit time | 1 ms |
| Bit order | MSB first, bytes back to back, no start/stop bits |
| Encoding | bit `0` = carrier on, bit `1` = LED off |
| Idle | LED off |
| Frame boundary | idle gap after each frame (the receiver uses it to find the next frame); 10 ms is reliable, the minimum is not yet known |
| Max frame | ~40 bytes used so far (2-byte header + up to ~35 text bytes + trailer) |

Generated by the ESP32 RMT peripheral (`main/src/ir_led_task.c`), so bit timing is hardware-exact.

## Frame formats

`[command] [byte 2] [text …] [trailer …]`

| Command | Layout | Meaning |
|---|---|---|
| `00` | `00 00 <text> <effect>` | Show text using transition `<effect>` (see below) |
| `04` | `04 <text>` | Show text immediately and scroll it; `04` alone blanks the display (community docs; not yet re-tested) |
| `05` | `05 00 <text> 00 <blink> <shift>` | Static text; used by the clock. Blink/shift semantics under test |
| `06` | `06` | Toggles scrolling (community docs; not yet re-tested) |
| others | – | under test |

## Transition effects (command `00`)

**Valid range: 0–37.** Effects 38–127 just blank the display (tested 38–64 and 100, plus 255).
**Bit 7 is ignored:** effect 128 behaves exactly like effect 0, so 128–165 mirror 0–37 (being confirmed with 129 and 140).

Unless noted, after the transition the text spins right → left at normal speed.

|---|---|---|---|

| 6 | Banner slides in, left → right | Pushed out ahead of the new text | |

## Open questions / next tests

- Effects 15, 22–37; confirm the bit-7 mirror with 129 and 140.
- Character set: which byte values `0x20`–`0xFF` render, and any special glyphs above `0x7F`.
- Text length: how many characters fit around the globe; scroll, cut off or wrap.
- Byte 2 of effect frames (always `00` so far).
- `05` blink and shift bytes; `05` byte 2.
- Unknown command bytes (`01`–`03`, `07`–`1F`, `80`, `81`, `FF`), with and without text.
- Minimum reliable idle gap between frames.
