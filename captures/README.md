# Camera captures

Drop videos of the globe here (any format the phone records: .mp4, .mov, ...).
They are git-ignored; only this README is tracked.

How to film:
1. Explorer tab -> pick "Transition effects" -> Camera run (8 s each is a good default).
2. Start recording before pressing Camera run, keep the phone steady, and film
   until it says "Done". The globe shows "FX nn" in every frame, so one long
   video is fine.
3. Tell Claude the file name; it extracts frames with ffmpeg, works out each
   effect and saves it as a "Proposed" profile for you to review and confirm.
